# 📁 Dossier PIX - Images du thème

## Images requises

### 1. Logo CEREDIS

**Nom du fichier** : `ceredis.png`

**Spécifications** :
- Format : PNG avec fond transparent
- Largeur : 250px (recommandé)
- Hauteur : Proportionnelle (environ 50px)

### 2. Image de fond Hero (élèves)

**Nom du fichier** : `hero-students.jpg`

**Spécifications** :
- Format : JPG ou PNG
- Dimensions : 1920x600px minimum (recommandé)
- Poids : < 500KB (optimisé)
- Contenu : Photo d'élèves en train d'apprendre

**Où trouver l'image** :
- Utilisez la photo de votre application "Billes & Calculs"
- Ou une photo similaire montrant des élèves avec du matériel pédagogique

### Chemins complets

```
/moodle/theme/ceredis/pix/ceredis.png
/moodle/theme/ceredis/pix/hero-students.jpg
```

### Si vous n'avez pas encore les images

Le thème fonctionnera avec :
- Un fond de couleur dégradé (sans image) si `hero-students.jpg` est absent
- Un espace vide pour le logo si `ceredis.png` est absent

### Optimisation des images

Pour de meilleures performances :
1. Compressez les images avec https://tinypng.com/
2. Redimensionnez à la taille exacte nécessaire
3. Pour le JPEG : Qualité 80-85% suffisante
